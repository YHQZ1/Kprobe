# Glossary

## Agent

The node-level kprobe recorder.

## Causal graph

A graph that connects events by cause-and-effect relationships.

## Kernel event

A timestamped record of kernel-observed runtime behavior.

## Recorder

The eBPF-based component that captures events from the Linux kernel.

## Replay session

An interactive reconstruction of an incident timeline.

## Service identity

The metadata that maps a process or container to a service name and environment.

## Trace correlation

The process of linking kernel events to OpenTelemetry traces, spans, and business identifiers.
